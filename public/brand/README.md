# Tony Muzo — Brand Kit

The mark is an **operator sigil**: a hexagon (security / tactical) housing a
`>_` terminal prompt (operator / engineering), in the site's cyan → blue →
violet palette.

## Files

| File | Use |
| --- | --- |
| `logo-mark.svg` | Scalable icon-only mark. Best for avatars, watermarks, favicons. |
| `logo-mark-1024.png` / `-512` / `-256` | Raster mark, transparent background. |
| `logo-full.svg` | Horizontal lockup (mark + wordmark) for **dark** backgrounds. |
| `logo-full-light.svg` | Horizontal lockup for **light** backgrounds. |
| `logo-full.png` | Lockup, 3040×880, transparent — for dark backgrounds. |
| `logo-full-light.png` | Lockup, 3040×880, transparent — for light backgrounds. |
| `../favicon.svg`, `../favicon-32.png`, `../apple-touch-icon.png` | Site icons. |

## Colors

| Token | Hex |
| --- | --- |
| Cyan (primary) | `#41d8ff` |
| Blue | `#5aa7ff` |
| Violet | `#a495ff` |
| Graphite base | `#04060b` |
| Surface | `#0d1626` |

Light-mode accents: cyan `#0369a1`, blue `#2563eb`, violet `#6d28d9`.

## Type

- Display / wordmark: **Chakra Petch** (700)
- Micro-labels: **JetBrains Mono** (500)

## Usage

Keep clear space around the mark equal to roughly half the hexagon's width.
Don't recolor the prompt, stretch the mark, or place the dark lockup on a
busy/low-contrast background — use the light variant instead.
